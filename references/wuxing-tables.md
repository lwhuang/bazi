## 天干五合

甲己合化土
乙庚合化金
丙辛合化水
丁壬合化木
戊癸合化火

合化條件：需得時得令，天干相鄰且地支有合化之根，方論化。僅合不化則為"合絆"，力量牽制。

## 地支關係

### 六沖
子午沖、丑未沖、寅申沖、卯酉沖、辰戌沖、巳亥沖

### 三合局
- 申子辰合水局
- 亥卯未合木局
- 寅午戌合火局
- 巳酉丑合金局

三合局需三字全見方成局，缺一則為半合（如申子半合水、子辰半合水），力量減半。

### 三會局（方局）
- 寅卯辰會東方木局
- 巳午未會南方火局
- 申酉戌會西方金局
- 亥子丑會北方水局

三會局力量大於三合局，需三字全見。

### 六合
子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合火（或合土，有爭議）

### 相刑
- 寅巳申三刑（無恩之刑）
- 丑戌未三刑（持勢之刑）
- 子卯相刑（無禮之刑）
- 辰辰自刑、午午自刑、酉酉自刑、亥亥自刑

### 相害（相穿）
子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害

## 十神定義及生剋關係

### 十神推導規則
以日干（日主）為中心，根據其他天干與日干的五行生剋關係及陰陽異同來確定十神：

| 關係 | 陰陽相同 | 陰陽不同 |
|------|---------|---------|
| 生我（我之母） | 偏印（梟神） | 正印 |
| 我生（我之子） | 食神 | 傷官 |
| 克我（克我者） | 偏官（七殺） | 正官 |
| 我克（我制者） | 偏財 | 正財 |
| 同我（同類） | 比肩 | 劫財 |

### 十神詳解

| 十神 | 含義 | 代表人事 |
|------|------|---------|
| 比肩 | 同我者，陰陽相同 | 兄弟、朋友、同輩、競爭者 |
| 劫財 | 同我者，陰陽不同 | 姐妹、競爭對手、損財者 |
| 食神 | 我生者，陰陽相同 | 子女（女命）、才華、口福 |
| 傷官 | 我生者，陰陽不同 | 子女（女命）、才藝、叛逆 |
| 偏財 | 我克者，陰陽相同 | 偏財、父（男命）、情人 |
| 正財 | 我克者，陰陽不同 | 正財、妻（男命）、穩定收入 |
| 偏官（七殺） | 克我者，陰陽相同 | 偏權、壓力、小人之類 |
| 正官 | 克我者，陰陽不同 | 正權、上級、夫（女命） |
| 偏印（梟神） | 生我者，陰陽相同 | 偏學術、繼母、孤獨 |
| 正印 | 生我者，陰陽不同 | 母親、學業、貴人 |

### 五行生剋
- 相生：木→火→土→金→水→木
- 相剋：木→土→水→火→金→木
