# 大運規則詳解

## 一、陽年與陰年

天干分陰陽：
- **陽年**：年干為甲、丙、戊、庚、壬
- **陰年**：年干為乙、丁、己、辛、癸

## 二、大運順逆規則

| 年干 | 性別 | 大運方向 |
|------|------|---------|
| 陽年 | 男 | 順排 |
| 陽年 | 女 | 逆排 |
| 陰年 | 男 | 逆排 |
| 陰年 | 女 | 順排 |

口訣：陽男陰女順排，陰男陽女逆排。

## 三、大運排列方法

以月柱干支為基準，進行順排或逆排：

### 順排
從月柱開始，天干和地支各往後推一位，依次排列。

例：月柱為丙寅，順排大運為：丁卯 → 戊辰 → 己巳 → 庚午 → 辛未 → ...

天干順推：甲→乙→丙→丁→戊→己→庚→辛→壬→癸→甲（循環）
地支順推：子→丑→寅→卯→辰→巳→午→未→申→酉→戌→亥→子（循環）

### 逆排
從月柱開始，天干和地支各往前推一位，依次排列。

例：月柱為丙寅，逆排大運為：乙丑 → 甲子 → 癸亥 → 壬戌 → 辛酉 → ...

天干逆推：癸→壬→辛→庚→己→戊→丁→丙→乙→甲→癸（循環）
地支逆推：亥→戌→酉→申→未→午→巳→辰→卯→寅→丑→子→亥（循環）

## 四、起運年齡計算

### 順排起運年齡
從出生日起，順數到下一個**節**（注意是"節"而非"氣"），計算總天數，除以 3，得數即為起運年齡。

公式：起運年齡 = 出生日到下一個節氣天數 ÷ 3

### 逆排起運年齡
從出生日起，逆數到上一個**節**，計算總天數，除以 3，得數即為起運年齡。

公式：起運年齡 = 出生日到上一個節氣天數 ÷ 3

### 十二節（用於起運計算）
立春、驚蟄、清明、立夏、芒種、小暑、立秋、白露、寒露、立冬、大雪、小寒

註：節與氣的區別——每月一節一氣，節為月之始，氣為月之中。排大運只看"節"。

### 餘數處理
- 余 1 天：約 4 個月起運
- 余 2 天：約 8 個月起運
- 余 0 天：整歲起運

四捨五入到最接近的整數歲數。

## 五、大運週期

每步大運管十年。

排列示例（假設 5 歲起運，月柱丙寅，順排）：
| 大運序 | 年齡範圍 | 干支 |
|--------|---------|------|
| 第一步 | 5-14 歲 | 丁卯 |
| 第二步 | 15-24 歲 | 戊辰 |
| 第三步 | 25-34 歲 | 己巳 |
| 第四步 | 35-44 歲 | 庚午 |
| 第五步 | 45-54 歲 | 辛未 |
| 第六步 | 55-64 歲 | 壬申 |
| 第七步 | 65-74 歲 | 癸酉 |
| 第八步 | 75-84 歲 | 甲戌 |

## 六、交運前的小運

小孩未交大運之前（即起運年齡之前），以月柱干支作為大運。

例：如果 5 歲起運，則 0-4 歲這段時間，以月柱的干支來分析運勢。

## 七、流年

流年即每一年的天干地支，用來判斷當年的運勢吉凶。

- 流年干支與原局（四柱）產生的關係（沖、合、刑、害等）影響當年運勢
- 流年與大運的關係也很重要：大運為環境，流年為引動
- 大運好、流年差：總體平穩但當年有波折
- 大運差、流年好：總體不利但當年有機遇

## 八、注意事項

1. 大運的交接年份（換運年）通常變動較大，需要特別關注
2. 大運天干管前五年，地支管後五年（此為一家之言，也有主張天干地支共管十年）
3. 大運與原局形成的天合地合、天克地沖等關係需要重點分析
4. 分析大運時要結合原局格局的喜忌，喜神到位則吉，忌神到位則凶
